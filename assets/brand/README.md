# kamaitachi logo, sky blue

A second logo for kamaitachi: a long, small-headed weasel whose tail curls round into a shape that is half wind and half sickle. It is drawn in sky blue (#79B9DE) on warm white (#F7F3EA), the colors of the joseon skin. The exe uses the cobalt seal in `assets/kamaitachi.ico`. This one is for places that want something lighter, like a light page header or a social card.

It was made with an image model, picked from two directions, and checked at the sizes icons are shown at. It is a raster, not a vector, so the blue varies a little from pixel to pixel. At 16 px the silhouette still reads but the eye is lost.
